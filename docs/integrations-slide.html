One engine: Guard

The SDK's Guard is the engine. The other three wrap it, so all four make the same decision on the same screen.

  • Screen cleaning
  • Action check
  • One policy.yaml
  • One decision log
  • Optional: Claude learns unknown apps
The agent has to reach the phone or its model somehow. Whichever path it takes, the same guard is on it. One server per phone: --device emulator-5556
